Three ways to allocate disk space

Contiguous

A file occupies consecutive blocks on the disk.

  • Fast sequential and random access
  • External fragmentation
  • Hard to grow a file

Linked

Each block stores a pointer to the next block of the file.

  • No external fragmentation
  • Files grow easily
  • Slow random access

Indexed

One index block holds the addresses of all the file's data blocks.

  • Fast random access
  • No external fragmentation
  • Index block overhead
